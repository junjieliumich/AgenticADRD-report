Data for analysis

Join on paper_id and experiment_id; add criterion_id for criterion/component tables. CSV files use UTF-8. Scores are 0, 1 or N/A. Preserve paper clustering when estimating uncertainty. Overlapping design labels require a many-to-many join.

  • papers.csv — One row per paper
  • experiments.csv — One row per study; role and design labels
  • criteria.csv — One row per scored experiment × criterion
  • components.csv — Component scores and evidence
  • design-labels.csv — One row per experiment × design label
  • criterion-summary.csv — Criterion totals by experiment role
  • assessments.json — Complete assessments and evidence
  • validation.json — Output checks and formatting corrections
  • prompt.md — Exact shared scoring prompt
  • data-dictionary.md — Variables and aggregation definitions
