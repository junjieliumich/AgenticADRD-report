Class 1 · Primary experiment. One participant-level random assignment created the information-only, nonreligious efficacy-boosting, and religious efficacy-boosting courses. The Lesson-1 information-versus-logistics contrast is an embedded diagnostic contrast generated by this same assignment, not a distinct randomization, so it is not double-counted as a separate experiment.
